## 📌 C++ Interview Questions for 6+ years experience (Persistent Systems)

---

## ✅ **C++ (6+ years experience level)**

* Differences between `std::unique_ptr`, `std::shared_ptr`, and raw pointers? When to use each?
* Copy constructor vs move constructor. When are move semantics triggered?
* Explain Rule of Three / Rule of Five in C++.
* Difference between `virtual`, `pure virtual`, and `override`.
* What is slicing? Example.
* How does C++ RTTI work? Downsides?
* What is placement new? Why use it?
* Difference between `std::map` and `std::unordered_map`. Trade-offs.
* Cost of dynamic polymorphism vs templates.
* Preventing inheritance in a class.
* `const` correctness: `const` member function vs `const` object.
* C++11/14/17/20/23 features you’ve used in real projects.

## 🧵 **Multithreading / Concurrency**

* Difference between process and thread.
* Mutex vs spinlock vs semaphore – when to use each?
* Explain deadlock. Strategies to avoid it.
* Implement a thread-safe queue.
* What are condition variables? How do they work?
* Multiple mutexes and lock order problems.
* Difference between `std::async`, `std::thread`, and thread pools.
* Explain atomic operations. When are they insufficient?
* What is false sharing? How to avoid?
* Design a producer-consumer system with multiple producers and consumers.
* How to profile and improve multithreaded code.

* Review your recent projects: usage of multithreading, C++11/14/17 features, memory management.
* Prepare 1–2 stories about debugging tough concurrency or performance problems.
* Refresh modern C++ idioms: RAII, smart pointers, move semantics, lambdas.
* Practice 2–3 LeetCode medium/hard problems.
* Know standard library containers & complexity.
